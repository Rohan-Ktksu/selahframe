# Third-party tools and sources

The project's MIT license covers its own code. It does not relicense dependencies,
models, music or supplied images. Downloads remain in ignored tools/ and voices/.
No weights or FFmpeg binaries are included in the source package or Git commit.

- Piper 1.8.0: GPL-3.0, https://github.com/OHF-Voice/piper1-gpl.
  Invoked as a separate local CLI; the installed --help and real synthesis were tested.
- Gyan FFmpeg essentials 9.0.2: GPLv3 build, https://www.gyan.dev/ffmpeg/builds/.
  Downloaded ZIP SHA-256: 60f467265b1e312373dbcd92200c2618a74850f98d3d078e94296bb3fa2047ba.
  Keep upstream notices and comply with its distribution terms if redistributing binaries.
- en_US-ljspeech-medium: https://huggingface.co/rhasspy/piper-voices/tree/main/en/en_US/ljspeech/medium.
  Model repository MIT; model card identifies a public-domain LJ Speech dataset.
  Dataset: https://keithito.com/LJ-Speech-Dataset/.
  Model SHA-256: 6f52a751e2349abe7a76735eb09dc1875298c77ea2342ffd2fef79ff81b87f22.
- Lessac was not downloaded. Its model card points to a research-only dataset license:
  https://www.cstr.ed.ac.uk/projects/blizzard/2013/lessac_blizzard2013/license.html.
  This is why the default changed from the original plan.
- Demo scripture: World English Bible Classic Psalm 23:1,
  https://ebible.org/eng-web/PSA023.htm, public domain per its linked notice.
  The stored scripture remains separate from the technical narration.
- Placeholder scenes are clearly labeled geometric illustrations generated by project
  code. They are not AI-generated biblical photographs.

New dependency set requirements-media.txt pins the tested local speech engine.
Piper's required ONNX runtime and NumPy run CPU inference; they add no paid API.
FastAPI/Starlette, Pydantic, Requests, Pillow, uvicorn, python-multipart and dotenv
retain their upstream licenses. httpx is used only by developer API tests.

Ruff 0.17.1 (MIT) is a developer-only dependency for lint and formatting checks.
